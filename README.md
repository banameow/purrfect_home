
# Purrfect Home

A cozy cat life simulation and room decoration mobile game built with Flutter, Flame, and Dart.

Take care of a virtual cat, interact with it, earn coins, purchase furniture, and decorate your own cozy home.

## Technologies

- Flutter
- Dart
- Flame Game Engine

## Prerequisites

Make sure you have installed:

- Flutter SDK
- Android Studio or VS Code
- Android Emulator or a physical Android device

Check your Flutter installation:

    flutter doctor

## Getting Started

### 1. Clone the Repository

    git clone https://github.com/banameow/purrfect_home.git

### 2. Navigate to the Project

    cd purrfect_home

### 3. Install Dependencies

    flutter pub get

### 4. Run the Application

    flutter run

Make sure an emulator or physical device is connected before running.

## Available Devices

To see connected devices:

    flutter devices

To run on a specific device:

    flutter run -d <device-id>

## Testing

Run tests:

    flutter test

Check code quality:

    flutter analyze
